# CyberSense — тренажёр по распознаванию мошенников

Учебный проект (Улан Ержанулы). Короткие уроки на карте-тропе: пользователь проходит разделы по порядку,
решает разные типы заданий, получает опыт (XP), звёзды и поддерживает серию дней.

## Как запустить локально

```
python -m pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000. Сайт полностью статический (папка `site/`): Python нужен только для локального просмотра.

## Публикация (GitHub Pages)

В репозитории есть `.github/workflows/pages.yml`: при каждом `push` в ветку `main` папка `site/`
автоматически публикуется на GitHub Pages.

Один раз в репозитории на GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Адрес сайта появится там же и во вкладке **Actions** после первой успешной публикации:
`https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как устроено

**Карта (`index.html`).** 5 разделов, в каждом 4 узла:
урок 1 → урок 2 → мини-квиз → испытание. Следующий узел открывается после прохождения предыдущего.
Пройденные узлы показывают звёзды и их можно повторять. У каждого раздела есть «Шпаргалка» с главными советами.

**Урок (`lesson.html`).** Задание → «Проверить» → панель с объяснением → «Дальше».
- Ошибка в обычном уроке возвращается в конце урока («Повторим ошибку»).
- Испытание — все ситуации и вопросы раздела в случайном порядке, 3 щита, без повторов.
- В конце: 1–3 звезды, опыт, процент с первой попытки, серия дней.

**8 типов заданий** (`js/exercises.js`):

| Тип | Что делает пользователь |
|-----|-------------------------|
| `verdict` | Оценивает ситуацию: Безопасно / Подозрительно / Мошенничество |
| `spot` | Отмечает подозрительные фрагменты в сообщении |
| `domain` | Нажимает на настоящий домен в адресе |
| `chat` | Выбирает ответ в переписке и видит последствия |
| `sort` | Раскладывает пункты по двум группам |
| `order` | Расставляет шаги по порядку |
| `tf` | Правда или миф |
| `choice` | Вопрос с вариантами (мини-квиз) |

**Игровые механики:** 10 XP за верный ответ с первой попытки, 5 — после повтора, +10 за урок,
+10 за урок без ошибок. Цель дня — 30 XP. Серия — дни подряд хотя бы с одним уроком.
Звёзды: 3 — от 90% с первой попытки, 2 — от 60%, 1 — урок пройден (в испытании — по числу оставшихся щитов).

## Управление

`1`–`9` — выбрать вариант, `Enter` — проверить / дальше, `Esc` — выйти из урока.

## Структура

```
cybersense/
├── app.py               Flask: только раздаёт папку site/
└── site/
    ├── index.html       Карта уроков
    ├── lesson.html      Прохождение урока
    ├── progress.html    Опыт, серия, звёзды по разделам, сброс
    ├── css/style.css    Все стили (цвета — в начале файла)
    └── js/
        ├── data.js      Темы, 20 ситуаций, мини-квизы (из Notion «Сценарии MVP»)
        ├── lessons.js   Уроки разделов: какие задания и в каком порядке
        ├── store.js     Прогресс (localStorage), серия, открытие узлов
        ├── ui.js        Иконки, шапка, отрисовка учебных интерфейсов
        ├── exercises.js 8 типов заданий
        ├── lesson.js    Логика урока
        └── map.js       Карта
```

## Как добавить задание

Откройте `site/js/lessons.js`, найдите нужный раздел и добавьте объект в `steps` урока.
Формат каждого типа описан в начале файла. Новая ситуация для `verdict` добавляется в `site/js/data.js`.
